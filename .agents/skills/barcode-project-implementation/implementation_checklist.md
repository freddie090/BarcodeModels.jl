# Project Implementation Checklist

## Pre-Implementation

- Target spec in project_specs/ identified explicitly.
- Spec includes all required sections from project_spec_template.md.
- Remaining ambiguities documented as clarification questions.

## Proceed Gate

- Final clarifications asked.
- Explicit user proceed confirmation received.

## Generation

- Scaffold directories created as specified.
- Script files created in required languages.
- Initial parameter tables created with required naming.

## Consistency

- Stage naming is consistent across scripts and outputs.
- Output directory contracts match specification.
- Uppercase path-token substitution applied (projects/Barcode_{UPPERCASE_PROJECT_TOKEN}).

## Verification

- Directory structure validated.
- Script inventory validated.
- Parameter-table presence validated.
- Mixed-case legacy project-root references not present unless explicitly requested.

## Documentation

- Implementation record created using implementation_record_template.md.
- Deviations and assumptions recorded.
